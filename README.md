# atlas-posthoc
Post-hoc diagnostics and manuscript-quality plotting for multi-chain `AtlasIO.jl` redistricting outputs.

`atlas-posthoc` is a Python toolbox for turning `AtlasIO.jl` chain outputs into reproducible convergence diagnostics, ensemble summaries, and publication-ready figures. The package is designed around the common workflow in computational redistricting research: run several independent chains, parse the saved map outputs, compute substantively meaningful observables, compare chains, and produce figures suitable for papers, talks, and internal reports.

The goal of this project is not limited to the redistricting research of any particular state, but to provide a reusable post-processing layer for future projects using `AtlasIO.jl` outputs.

## What It Is

Given multiple AtlasIO.jl output files, typically four independent chains, `atlas-posthoc` aims to produce:

- robust parsing summaries for `.jsonl` and `.jsonl.gz` AtlasIO outputs;
- canonical district assignment tables;
- ordered vote-share marginals by chain;
- ordered compactness or isoperimetric-score marginals by chain;
- max average pairwise total-variation convergence curves;
- enacted/reference-plan overlays;
- convergence-gated enacted/reference-plan comparisons;
- manuscript-ready maps and diagnostic plots;

We underscore this workflow: We first establish that the ensemble is trustworthy on the observables of interest. Then we use that ensemble to evaluate the enacted plan.

## What It Is Not

`atlas-posthoc` is not a redistricting sampler. It does not generate plans. It assumes that sampling has already been performed elsewhere, usually through `AtlasIO.jl` or related Julia redistricting tools. In fact, the first application of this package is to analyze plans generated by samplers based on `CycleWalk.jl` and `MetropolizedForestRecom`. 

It also does not attempt to be a universal redistricting analysis framework. The first goal is narrower and more practical: provide a trustworthy, reusable post-hoc pipeline for multi-chain `AtlasIO` outputs.

## Project status

This package is still under active development.

The first stable target is a diagnostic suite inspired by [this Connecticut redistricting paper](https://arxiv.org/abs/2401.17455):

- parse AtlasIO output files;
- compute ordered vote-share vectors;
- extract ordered compactness vectors;
- compute four-chain total-variation diagnostics;
- generate marginal and convergence plots;
- generate reusable convergence reports and cached manifests.

PACE and graph-partition distance workflows now live in the sibling
[`pace-for-atlas`](https://github.com/franklinxzhou/pace-for-atlas) project.

## Quick Start

### Install from GitHub

For regular users, install directly from the GitHub repository:
```
pip install "git+https://github.com/franklinxzhou/atlas-posthoc.git"
```
or, using `uv`:
```
uv pip install "git+https://github.com/franklinxzhou/atlas-posthoc.git"
```

For development, clone the repository and install it in editable mode:
```
git clone https://github.com/franklinxzhou/atlas-posthoc.git
cd atlas-posthoc
pip install -e .
```
or, with `uv`:
```
git clone https://github.com/franklinxzhou/atlas-posthoc.git
cd atlas-posthoc
uv pip install -e .
```
